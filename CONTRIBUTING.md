# Contributing

Mukoz is developed by CAPH TECH Inc. We do not accept pull requests or other code contributions
at this time. Pull requests will be closed without review.

Bug reports and questions are welcome as GitHub issues. Please include:

- the Mukoz version (`CHANGELOG.md`) and the host (`mukoz platform probe`);
- the suite, contract, binding and artifact needed to reproduce, or the smallest you can share;
- the `mukoz` JSON output.

For security problems, see [SECURITY.md](SECURITY.md) instead of opening a public issue.
